Evaluation Protocol

NeuroMIB evaluates interpretability quality across four tasks. Public track resources are available for local iteration, while private track resources are used for final ranking and anti-overfitting evaluation.

  • Task A: latent variable recovery
  • Task B: mechanism classification
  • Task C: support recovery
  • Task D: intervention prediction
