Benchmark

NeuroMIB

A mechanistic interpretability benchmark for systems neuroscience through neural dynamics.

NeuroMIB evaluates whether an interpretability method can recover latent variables, mechanism class, computational support, and intervention effects from models trained on synthetic population dynamics.

GitHub Repository Back to Main Site

Core Benchmark Tasks

Task A: Latent Recovery

Recover hidden trajectories such as ring angle, evidence state, context, and communication state.

Metrics: R2, circular correlation, mutual information, subspace correlation.

Task B: Mechanism Classification

Predict mechanism class across ring, rotation, decision, switching, low-rank, communication, or mixed.

Metrics: exact accuracy, top-2 accuracy, mixed-case partial credit.

Task C: Support Recovery

Identify where computation lives across channels, time, regions, and model-internal components.

Metrics: AUROC, AUPRC, IoU, top-k precision, sparse-support F1.

Task D: Intervention Prediction

Predict effects of lesioning, shuffling, clamping, modality silencing, and pathway/subspace disruptions.

Metrics: effect correlation, MAE, rank consistency.

Public and Private Tracks

Public Track

  • Released generators, configurations, and scoring code
  • Public train/validation and visible test split
  • Local iteration and public leaderboard submission

Private Track

  • Hidden generator combinations and noise regimes
  • Hidden interventions and labels
  • Final ranking based on private evaluation only

Python Package and CLI

NeuroMIB ships as a Python package with reproducible generation and scoring commands.

neuromib-generate --config neuromib/configs/public/family1_public.yaml --output data/public/family1
neuromib-validate-submission --submission-dir submissions/example
neuromib-score --instance data/public/family1/instance_000.npz --hidden data/public/family1/instance_000_hidden.npz --submission-dir submissions/example
